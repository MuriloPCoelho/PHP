# Projeto 07 — Blogging Platform API (projeto final pré-Laravel)

Baseado em: https://roadmap.sh/projects/blogging-platform-api

> Este é o checkpoint da Fase 5. Objetivo: API completa em PHP puro — rotas, controllers, camada de banco via PDO, autenticação, validação, testes básicos. Depois de pronta, a mesma API será **refeita em Laravel** (já na Fase 6) para comparar diretamente o antes/depois e entender, na prática, quais problemas o framework resolve (roteamento, ORM/Eloquent, autenticação, validação, etc.).

Será detalhado quando as Fases 1–4 estiverem completas.
